# SMSO — Система Мониторинга и Ситуационного Освещения

Веб-приложение для оперативного реагирования на чрезвычайные ситуации и координации служб быстрого реагирования.

## 📁 Структура проекта

```
smso/
├── index.html          # Главная страница / Лендинг / Вход в систему
├── dispatcher.html     # Рабочий стол диспетчера
├── admin.html          # Панель администратора
└── README.md           # Документация
```

## 🚀 Быстрый старт

1. Откройте `index.html` в любом современном браузере
2. Войдите под одним из тестовых пользователей:
   - **Администратор**: `admin` / `admin123`
   - **Диспетчер**: `disp1` / `disp123`

## 🔑 Ключевые возможности

### ✅ Исправленные баги
- **Иконки переключателя темы** — используются встроенные SVG (без внешних зависимостей)
- **Стабильность Яндекс Карт** — инициализация через `ymaps.ready()`, `fitToViewport()` при ресайзе
- **Адаптивный сплит-экран** — плавная обработка событий мыши для изменения размера панели

### 🎨 UI/UX улучшения
- CSS Grid для карточек событий (`repeat(auto-fit, minmax(280px, 1fr))`)
- Плавные переходы между светлой и тёмной темой
- Всплывающие уведомления об успешных действиях
- Модальные окна для обработки событий

### 💾 localStorage Архитектура

Единый модуль `Storage` с ключами:
- `ls_users` — пользователи (логин, пароль, роль, статус)
- `ls_events` — события (тип, координаты, статус, решение)
- `ls_session` — текущая сессия
- `ls_theme` — тема оформления (light/dark)

### 📊 Mock Data по умолчанию

**Пользователи:**
- `admin` / `admin123` (роль: admin)
- `disp1` / `disp123` (роль: dispatcher)

**События (5 шт):**
- 4 активных (пожар, подтопление, несанкционированный доступ, отказ датчика)
- 1 завершенное (ликвидированное возгорание)

## 🗺️ Яндекс Карты

Для работы карт получите бесплатный API-ключ в [Кабинете разработчика Яндекс](https://developer.tech.yandex.ru/) и замените `your-api-key` в файлах `dispatcher.html` и `admin.html`:

```html
<script src="https://api-maps.yandex.ru/2.1/?apikey=YOUR_API_KEY&lang=ru_RU"></script>
```

## 🌓 Тёмная тема

Переключение темы осуществляется кнопкой в шапке. Выбор сохраняется в `localStorage` и применяется при следующем входе.

## 🔐 Ролевая модель

| Роль | Доступ |
|------|--------|
| **admin** | Все функции диспетчера + управление пользователями |
| **dispatcher** | Просмотр карты, обработка событий, история |

## 📝 Обработка событий

1. Диспетчер выбирает активное событие
2. Нажимает «Обработать»
3. Выбирает действие и добавляет комментарий
4. Статус меняется на `resolved`
5. Цвет метки на карте → зелёный
6. Карточка перемещается во вкладку «Завершенные»

## 👥 Управление пользователями (Admin only)

- Создание новых диспетчеров/администраторов
- Блокировка/разблокировка аккаунтов
- Удаление пользователей (кроме системного `admin`)
